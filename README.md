# حياتي — PWA

نسخة قابلة للتثبيت من ملف `life.html` الأصلي، مع الحفاظ على أقسام التطبيق وأسلوبه البصري، وإضافة:
- Web App Manifest واسم وأيقونات للتطبيق.
- Service Worker لتخزين ملفات التطبيق الأساسية والعمل دون اتصال بعد أول تحميل.
- زر تثبيت يظهر عندما يدعم المتصفح طلب التثبيت.

## طريقة التشغيل والتثبيت على Android

1. ارفع محتويات هذا المجلد إلى استضافة تدعم HTTPS، مثل GitHub Pages أو Netlify أو Vercel.
2. افتح رابط الموقع باستخدام Chrome على Android.
3. استخدم زر **تثبيت تطبيق حياتي** إن ظهر، أو من قائمة Chrome اختر **تثبيت التطبيق** / **إضافة إلى الشاشة الرئيسية**.
4. افتح التطبيق مرة أثناء الاتصال بالإنترنت حتى تُخزّن الملفات الأساسية للاستخدام دون اتصال.
5. من قسم «الدين»، اضغط «استخدم موقعي الحالي» واسمح بإذن الموقع. يلزم HTTPS لتحديد الموقع في المتصفحات الحديثة.

> ملاحظة: PWA لا يُثبت مباشرة من ملف HTML محلي. يلزم HTTPS (أو localhost للتجربة). لم يتم إنشاء APK لأن المطلوب هو PWA.

## البيانات والخصوصية

- بيانات المتابعة تُحفظ محليًا في تخزين المتصفح (`localStorage`) على نفس الجهاز والمتصفح.
- لا توجد مزامنة سحابية أو حساب مستخدم في هذه النسخة.
- مسح بيانات الموقع أو المتصفح قد يؤدي إلى فقدان البيانات؛ يُنصح بتصدير/نسخ البيانات يدويًا قبل حذف بيانات المتصفح.

## نقاط تحتاج اختبارًا على الجهاز الحقيقي

- مواقيت الصلاة تستخدم إحداثيات GPS الحالية عند الضغط على «استخدم موقعي الحالي» والسماح للمتصفح بالوصول للموقع. تُحفظ آخر إحداثيات محليًا على الجهاز. إذا رفضت الإذن، يبقى الحساب على إحداثيات احتياطية تقريبية؛ راجع المواعيد محليًا قبل الاعتماد عليها.
- اتصال Bluetooth بقياس النبض يعتمد على دعم المتصفح والساعة لبروتوكول Heart Rate Service القياسي؛ بعض الساعات وتطبيقات الشركة لا تتيح ذلك مباشرة.
- يجب اختبار تثبيت PWA والعمل دون اتصال على الاستضافة المستهدفة.
